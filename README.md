# Manipulator2 (6-DOF Robotic Arm with Forearm Vision Rig)

Роботизированная рука-манипулятор с 6 степенями свободы (6 DOF) и клешней-захватом, способная находить на плоском столе объекты по жесту указания пальцем оператора (включая объекты вне начальной зоны видимости камеры) и переносить их к основанию руки.

## Особенности архитектуры
- **Сенсорная платформа на предплечье**: Камера **OV5647** и ToF-дальномер **VL53L0X** установлены на звене предплечья манипулятора.
- **Тонкий клиент**: **Raspberry Pi Zero 2 W** в связке с протоколом **Zenoh** (минимальный оверхед, только опрос сенсоров и управление сервомоторами).
- **Толстый клиент**: Ноутбук (AMD Ryzen 5, 16 ГБ ОЗУ) с полным конвейером обработки:
  - **MediaPipe Hands**: Детекция руки и расчет 3D-луча указательного пальца с пересечением плоскости стола.
  - **YOLO11n**: Детекция целевых объектов на столе.
  - **IKPy**: Прямая и обратная кинематика 6-DOF манипулятора.
  - **Активный поиск**: Автоматическое панорамное сканирование предплечьем сектора стола, если объект находится вне поля зрения камеры.
- **Симуляция (Digital Twin)**: Полная физическая симуляция в **MuJoCo** на основе модели `urdf_model/root_mujoco.urdf`.
